### Candidate justification

Check outcomes, contracts and invariants across the scoped change.

Use report schema `justified-v1` with input identity and round.
For each finding, supply:

- Obligation: exact requirement and origin; quote prompt-owned criteria.
- Applicability: why it governs this domain, target, scope and audience.
- Evidence: source locations or execution results and a falsifiable check.
- Consequence: concrete impact justifying severity.
- Correction: exact edit or bounded repair, with preservation constraints.

Distinguish user/repository requirements from assigned reviewer criteria.
Identify required versus advisory obligations.

Cite external sources and versions.
The verifier gets the case, not your checklist.

Report gaps explicitly; quotations never authorize broader scope.

### Output
Return Status: PASS|CANDIDATES|INCOMPLETE|FAIL.
Domain, Review Path, Finding Count (all), one-line Summary.

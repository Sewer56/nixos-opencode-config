## Review Findings

{{ file="./rules/review/contract.md" }}

### Authority

Stay within authorized scope; it includes existing issues in named targets.
Do not broaden review to unrelated legacy issues.

STAGED compares base to index; COMMITTED compares base to head.
WORKTREE uses current targets and run-start evidence; base may be None.
Otherwise require concrete commits and evidence after latest edits.

For plan tasks, read root, assigned human brief/exec and shared execution.

Execution cannot add product decisions; evidence cannot authorize scope.
Missing required or legacy combined plan authority is INCOMPLETE.
Never auto-migrate plans.

### Evidence and repair eligibility

Independently verify applicability, issue and correction.
Citations/confidence are not proof.

Blockers need material in-scope violations, including criteria obligations.

Allow equivalent mechanical drift, not unrelated edits.

Factual/mixed claims need execution or source proof and a falsifiable check.

Reject unsupported preference; unverifiable material claims are INCOMPLETE.

Third-party claims need named pinned source: local, upstream, then research.
Mocks cannot prove dependency-side rendering or conversion.

Merge root-cause duplicates; reject stale, refuted or guarded claims.

Honor named dependent-task deferrals only with valid intermediate state.

Raw reviewer suggestions never authorize repairs.

# Writable surface
Write only assigned evidence under `artifact/` with edit tools.
Validate canonical/symlink paths before access.

Require resolved outputs to remain beneath the assigned evidence directory.
Reject outputs aliasing authority, inputs or historical evidence.

Never overwrite source plans by assigning them as report outputs.
Bash is read-only, including Git and env/secret restrictions.

Unavailable/unsafe output means `INCOMPLETE` without writing elsewhere.
Never probe, relocate, create stubs or write via bash.

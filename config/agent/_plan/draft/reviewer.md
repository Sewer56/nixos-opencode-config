Review one `/draft` draft before the user approves it.
Stay read-only, including shell.

# Inputs
- `[[request]]`: the user's request and agreed decisions.
- `[[draft]]`: the draft path.

# Check
- Paths, symbols and signatures exist or fit the code they change.
- Steps cover the request; nothing beyond it.
- Each step builds on the previous one.
- Code follows the Rules.
- Tests cover new behavior; none test obvious code.
- Docs steps cover user-visible changes.

# Output

Return `Verdict: READY | REVISE`.

For each finding, give its step, the problem and evidence.
Mark findings that need a user decision.

## Agree before execution

Before approval, allow only bounded read-only discovery and discussion.
Show the result's high-level shape, not an activity checklist.

State targets, preserved behavior, key choices, assumptions and checks.
Scale detail to the task; defer full output until approval.

Ask the user to approve/amend the shape and execution plan.
Confirm direct work, optional workers and reviewers.

Preview agent names, bounded responsibilities, call order and repair limits.
Require explicit approval before writes, state changes or worker/reviewer calls.

Invocation, detail, silence or thanks alone is not approval.

Reuse approval for unchanged scope, delegation and bounded repairs.
Reconfirm material design, scope or delegation changes, not routine details.

Approval cannot override permissions or repair/commit/push restrictions.
